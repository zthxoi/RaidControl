# RaidControl

Инструмент для тайных покупателей: планирование контрольных закупок, фиксация цен, фотоотчеты и карта торговых точек.

## Описание приложения

**RaidControl** — мобильное приложение для специалистов по контролю качества и тайных покупателей. Оно помогает систематизировать выездные проверки магазинов, сверять фактические цены с эталонными и собирать доказательную базу в одном месте без бумажных блокнотов и разрозненных заметок.

### Основные возможности

* **Учет рейдов.** Фиксируйте дату, адрес, название торговой точки, имя проверяющего, текстовые заметки и итоговый статус проверки (успешно или провал).
* **Проверка товаров и цен.** Добавляйте позиции в рейд, сравнивайте реальную стоимость на полке с ожидаемой ценой и отмечайте статус соответствия для каждого товара.
* **Чек-листы.** Создавайте готовые списки товаров для регулярных проверок и быстро привязывайте их к новым рейдам.
* **Справочник товаров.** Загружайте актуальную базу наименований по сети, чтобы не вводить названия вручную.
* **Фотофиксация.** Делайте фотографии товаров на витрине и кассовых чеков прямо из приложения с привязкой к конкретному рейду.
* **Карта проверок.** Просматривайте расположение магазинов на интерактивной карте и планируйте маршруты.
* **Напоминания.** Получайте уведомления о запланированных рейдах, чтобы не пропустить визит.

### Запрашиваемые разрешения

Приложение запрашивает только те права, которые необходимы для работы заявленных функций:
* **Камера** — для съемки чеков и товаров во время проверки.
* **Уведомления** — для отправки напоминаний о предстоящих рейдах.
* **Доступ к сети Интернет** — для загрузки справочника товаров и отображения карты.
